# Security policy

## Reporting a vulnerability

Email **support@armoreum.io** with the subject `Security report: Armoreum`.

Include affected source files or commit, a clear description, prerequisites, impact, and a minimal synthetic reproduction. Do not include a live private key, token, password, recovery capsule, seed phrase, or customer data.

Please avoid public disclosure until the issue can be assessed. No response deadline or bounty is promised by this policy.

## Support scope

The current release is a source preview. There is no production-supported version or independently verified deployment established by this repository. Report issues against the current `main` branch or identify the exact release tag.

If a credential has been disclosed, revoke or rotate it at its provider. Deleting the file or message does not make the credential safe.

This source publication is not a security audit, a post-quantum certification, or a guarantee of asset safety.
