# Contributing to Armoreum Authorization

Issues and pull requests are open. Read the README, [source scope](docs/source-scope.md), [security policy](SECURITY.md), and [Code of Conduct](CODE_OF_CONDUCT.md).

1. Fork the repository and branch from `main`.
2. Make one focused change; use English for documentation and product copy.
3. Add synthetic tests and run `npm test`. Report exact commands and any unavailable checks.
4. Open a pull request describing behavior, compatibility, security implications, and remaining limitations.

Never include live keys, credentials, real recovery files, customer records, database dumps, or funded production transactions. Report vulnerabilities privately to **support@armoreum.io**.

Copied module sources have explicit provenance. When proposing protocol or shared-source changes, explain the corresponding change needed in the canonical application or contract repository. Do not silently diverge shared security logic.

Project-owned contributions are submitted under the MIT License. Preserve third-party licenses and required attribution.
